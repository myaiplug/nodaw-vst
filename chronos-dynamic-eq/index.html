In this demo vs the plugin

What’s real here.

  • PortedThe engine: all seven bands with Static, Compress and Expand modes, threshold, ratio, range, attack, release and per-band Solo, plus the global Dynamics amount and master section.
  • ParamsAll 88 parameters plus bypass, with the plugin’s own ranges, units and curves (89 host parameters in the plugin).
  • PresetsAll 12 factory presets, by name and value, read from the plugin’s preset files.
  • A/BBypass uses the engine’s own crossfade to the latency-delayed dry signal, so the switch never clicks.
  • Plugin onlyThe plugin’s analyser with per-band gain-reduction display (here the live band gains show as numbers top-right)
  • Plugin onlyDAW automation, MIDI learn, undo/redo, A/B slots and user presets
  • LimitsThere is no linear-phase mode. The bands are minimum-phase only.
  • StatusThe Chronos Dynamic EQ plugin (VST3 + CLAP, Windows x64) is in development: unreleased, not for sale, no price yet.
Signal flow

Chronos Dynamic EQ, stage by stage.

Input→Band 1→Band 2→…→Band 7→Dynamics amount→Mix→Output

Per-band dynamics

Threshold, Ratio, Range up to 24 dB, Attack and Release on every band, with node rings showing each band’s live gain.

Solo any band

Audition a band on its own. An idle band is bit-transparent, and gain changes are zipper-free.

See the move

The live curve, the dashed static curve, a threshold marker and band chips with ring meters. The GR meter shows the deepest cut.

Master

Input, Output, Mix and a Dynamics amount from 0 to 200 % that scales every band’s range, capped at 24 dB.

How a band works

Each band is x + (G−1)·F(x), so a band that is doing nothing passes audio untouched.

Zero latency

The bands are minimum-phase IIR filters, so nothing is added to your session delay.
